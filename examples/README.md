# dlux example: TCGA BRCA-vs-COAD subtyping

A complete, reproducible run of the dlux pipeline on public data with a public model. It trains a binary subtyping classifier (BRCA vs COAD) from H&E whole-slide images, on a small pinned TCGA subset, using the Phikon foundation model. It develops on one center (Christiana Healthcare) with nested cross-validation, then validates on a second center (MSKCC).

This project ships pointers and code, never pixels. You fetch the slides from GDC, the model from HuggingFace, and `ahcore` from PyPI. dlux ships no data.

## Run it

The full step-by-step walkthrough, with context and prerequisites, is the tutorial: **[docs/tutorials/tcga_subtyping.md](../docs/tutorials/tcga_subtyping.md)**.

## What is in here

- `catalog/` holds the two cohorts, the study, and the `baseline` experiment.
- `config/` holds the Phikon feature-extractor config and the cohort input-path structure.
- `scripts/tcga_subtyping/` holds `make_manifest.py` (pin the slides from the GDC API) and `build_sheets.py` (turn the gdc-client output into the rigid sheets).
- `local_paths.example.yaml` is the paths file for a public clone. Copy it to `config/local/paths/default.yaml`; it reads the output root from the `DLUX_ROOT` env var, so there is nothing to edit. The cohort data root is the `DLUX_EXAMPLE_DATA` env var.
